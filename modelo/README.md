# ROBOHUB — páginas HTML

Arquivos:
- index.html — entrada, redireciona para a trilha
- trilha.html — dashboard/trilha de conhecimento
- programar.html — editor de blocos + simulador
- styles.css — identidade visual compartilhada
- app.js — interações e simulação básica
- robot.svg — ilustração do robô

## Como usar
Abra `index.html` ou `trilha.html` no navegador.

Tudo é front-end puro, sem framework e sem dependências externas. A lógica de backend, autenticação, salvamento de programas e simulador físico/3D real pode ser conectada depois.

## Observação
Os blocos foram desenhados com encaixe visual superior/inferior para aproximar a experiência de programação por blocos do SPIKE. O editor já permite clicar nos blocos da paleta para adicioná-los e clicar em blocos adicionados para removê-los.
